# Approved hero implementation brief
User requested implementation of the Spider-Man-inspired homepage hero concept,
using their newly uploaded portrait without changing facial identity. Scope: hero only.
Built-in imagegen: character layer uses portrait as strict face, hair, glasses, beard
reference; navy shirt, charcoal trousers, white sneakers, diagonal swinging pose,
forward right fist. Transparent output. Background: empty ivory field, red/black
halftone corners, blue/navy Dhaka-inspired skyline at bottom, no text or people.
Live text, icons and web geometry authored separately for animation and accessibility.
